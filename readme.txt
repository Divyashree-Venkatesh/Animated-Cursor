## Animated Cursor Collection

A collection of creative and interactive animated cursor effects built using **HTML, CSS, and JavaScript**.

## ✨ Features

- Smooth animations
- Lightweight implementation
- Interactive cursor behavior
- Works in modern browsers
- Customizable colors, emojis, particles, and effects

---

## 🎨 Cursor Effects Included

### Cute / Playful
- Animal Collector Tail
- Butterfly Swarm
- Bubble Cursor etc

---

## 📖 Effect Descriptions

### Animal Collector Tail
Collect animals and build a dynamic tail that follows the cursor.

### Butterfly Swarm
Tiny butterflies float and follow the cursor with a natural swarm motion.

### Bubble Cursor
Creates floating bubbles that appear and fade during movement.

### XP Collector Cursor
Collect stars and gain XP while growing a trailing effect.
